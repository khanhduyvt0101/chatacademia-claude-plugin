# ChatAcademia branding

`assets/chatacademia-icon.png` is the plugin icon (512 x 512 PNG, transparent corners), referenced by the `icon` field of `.claude-plugin/plugin.json`. `assets/chatacademia-icon.svg` is the vector source (the existing ChatAcademia favicon, unchanged); the PNG is that SVG rendered at 512 px.

Use the mark without recoloring, distortion or decoration. The ChatAcademia name and logo remain trademarks of ChatAcademia; the MIT license in this repository does not grant rights to them beyond showing this plugin.
