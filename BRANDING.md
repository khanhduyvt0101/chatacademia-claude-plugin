## Claude display limits

The current documented Claude plugin manifest supports `displayName`, author, homepage and repository metadata but does not document a logo/icon field. `displayName: ChatAcademia` preserves readable product casing. Putting an asset in `assets/`, the README or arbitrary `metadata` does not establish that Claude will render it as the plugin's icon.

Directory branding must use a supported submission/reviewer mechanism. No catalog acceptance or logo display is claimed until observed in Claude.
